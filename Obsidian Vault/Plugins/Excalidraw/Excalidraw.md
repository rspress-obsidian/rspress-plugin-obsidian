# Excalidraw

The drawings in this folder are saved in the format of the
[Excalidraw plugin](https://github.com/zsviczian/obsidian-excalidraw-plugin):
a markdown note with `excalidraw-plugin: parsed` frontmatter and a compressed
scene, and a plain `.excalidraw` JSON file. The site draws them at build time
as SVG, with Excalidraw's own hand-drawn strokes.

- [[Excalidraw Showcase.excalidraw]]: every element type, arrowheads, fills,
  frames, an embedded image and links.
- [[Plain Drawing.excalidraw]]: a plain `.excalidraw` file, published as its own page.
- [[Embedded Diagrams.excalidraw]]: a Mermaid diagram and a PDF page inside a drawing.
