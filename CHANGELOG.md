# Changelog

## Pre-release development

Release sections are written above this one by semantic-release from Conventional Commits; edit commit messages, not this file. This package has not been published before its first release, so it carries no migration notes of its own. The graph view was published separately as `rspress-plugin-graph-view` (latest 1.1.3); moving from it is a change of import and plugin name, described under "Coming from `rspress-plugin-graph-view`" in the README. What the first release contains, in summary:

- One package, `rspress-plugin-obsidian`, merging three earlier plugins (wikilink, canvas, graph view). Factories `markdown()`, `canvas()` and `graphview()`, plus the `pluginObsidian()` umbrella; plugin identities `rspress-plugin-obsidian:markdown`, `:canvas` and `:graph`.
- Markdown: wikilinks and Markdown links resolved against the vault, transclusion, callouts, media embeds, tags and tag pages, backlinks and unlinked mentions, footnotes, comments, highlights, math (KaTeX by default, MathJax opt-in), Mermaid, Dataview (DQL, inline fields and a restricted DataviewJS interpreter), daily notes and `obsidian://` links. Coverage is listed per feature in `docs/obsidian-compatibility.md`.
- Obsidian community and core plugins, reimplemented as opt-in build-time renderers that read the vault's own plugin settings (`.obsidian/plugins/<id>/data.json`; site options win). Blocks a plugin cannot render are shown in place and fail the build by default (`onPluginError`); a fence from a plugin the site has not enabled stays code with a warning naming the option.
  - Tasks (`enableTasks`): ` ```tasks ` queries over every published task — status, date (natural-language), text, priority, recurrence (read and restated by rrule) and dependency filters, Boolean logic, sort, group, limits, layout options, list and columns views, `explain`, presets, placeholders and query-file defaults — rendered with Tasks' markup and classes; custom statuses, the global filter and query, and filename-as-scheduled-date from the vault's settings.
  - Kanban (`enableKanban`): notes with `kanban-plugin` frontmatter publish as read-only boards in Kanban's `kanban-plugin__*` markup, on their page and in embeds — lanes, WIP limits, complete lanes, the archive (`kanban.showArchive`), dates and times read with Moment's forgiving parser as Kanban reads them, relative dates and colours, tags and tag colours, linked-note and inline metadata, and the list and table views.
  - Excalidraw (`enableExcalidraw`): drawing notes and plain `.excalidraw` files drawn at build time as static SVG with Excalidraw's own hand-drawn strokes, as pages, `![[Drawing]]` embeds (width, height, element/group/area/frame crops) and fences; links resolve, vault images and PDFs are served, Mermaid diagrams and PDF pages inside a drawing render, changed text is wrapped with Excalidraw's own algorithm, auto-exported images can be preferred, and Excalidraw's fonts and exact text metrics come from the optional `@excalidraw/excalidraw` peer.
  - Bases (`enableBases`): `.base` files publish as pages under `bases.routePrefix`, and `![[x.base]]` / `![[x.base#View]]` embeds and ` ```base ` blocks render in place — filters, formulas with the full function library, date arithmetic, `this`, property types, and table, cards, list and kanban views with sort, group, `groupOrder`, limit, summaries and a view switcher that needs no JavaScript. Map views are interactive MapLibre maps (optional `maplibre-gl` peer, OpenFreeMap tiles by default, `bases.mapTiles`), falling back to a table. A conformance suite checks the evaluator against 294 results recorded from a running Obsidian (293 match; backlink order differs).
  - Templater (`enableTemplater`): the templates folder stays private; daily-note, folder and file-regex templates fill empty notes; `<%+ %>` dynamic commands render at build time; other commands stay as written with a warning (or run with `templater.renderCommands: "all"`). Commands run in an interpreted JavaScript subset with `tp.date`, `tp.file` (including `include`), `tp.frontmatter`, `tp.config`, `tp.hooks` and `moment`, never `eval`; prompts, file changes, network calls and user scripts render a static equivalent and are reported.
- Canvas: published boards with groups, edges, file, link and text cards, plus embeds of boards inside notes.
- Graph view: a local and global graph panel with search, filters and hover previews.
- Hover previews are Obsidian's Page preview: they render the linked note (only the section or block for `#heading` and `#^id` links) in a scrollable popover anchored to the link that flips above it to fit, stay open while the pointer is on the link or the popover, close on Escape, and fire only for mouse hovers over article links. The preview stays open when content above the link finishes loading (a Mermaid diagram, an image) and closes on a scroll only when the link itself moves. The `virtual-page-content-data` module and its 300-character excerpts are gone, and so are the `.obsidian-hover-preview__header`, `__title` and `__content` classes; the popover body is `.obsidian-hover-preview__body`.
- Obsidian's own semantics are the defaults: links resolve the way Obsidian picks them (same folder, then shortest path; `onAmbiguousLink` warns), link text shows the target as typed, vault notes render soft line breaks (`strictLineBreaks`), Dataview inline queries use Dataview's `` `= expr` `` syntax, and only referenced attachments are published — from a plugin-owned directory, never written into `docs/public/`.
- A vault note is titled by the `# heading` it renders, or by its file name when it renders none (Obsidian's inline title); output headings (Tasks groups, Bases views, the backlinks panel) stay out of the page outline, and an Excalidraw note's data headings stay out of the index. A page that fails the build lists every deferred diagnostic in the failure itself.
- An escaped `\#word` stays text, as in Obsidian, instead of becoming a link to a tag page that does not exist; tag pages no longer title themselves with a link to themselves. The graph panel does not auto-open (`defaultOpen`) on screens narrower than 640px, where it covered half the article.
- Checked against the plugins' own documentation examples: Tasks runs `{{! … }}` comments in queries; Templater's `tp.file.create_new` returns the file it would have created (so a link to it reads `[[MyFilename]]`, not `[[undefined]]`), a failed command inside a link becomes its error marker instead of leaking a placeholder into the link, and block ids a template brings in are hidden and anchored.
- Styles meet WCAG AA in light and dark mode: callouts tint the whole card and keep inline title markup together; no stray theme divider inside backlinks, transclusions, callouts, Kanban and canvas cards; muted, danger and link colours on plugin surfaces pass contrast; Kanban's configured colours are lifted in dark mode; dates never break at their hyphens; tables and boards scroll inside their own box at phone widths.
- Vault code is sandboxed: DataviewJS, DQL, Templater commands, Bases formulas and Tasks queries are interpreted, never evaluated; prototype access is refused however the name is built; user regexes that could backtrack catastrophically are refused at every site; text and list sizes are capped; runaway scripts stop at step budgets; and a stack overflow is reported instead of crashing the build.
- Date arithmetic lives in one module with each language's own library semantics — Moment for Templater, Kanban, Bases and daily notes, Luxon for Dataview — checked against the real libraries.
- Math is typeset at build time and handed to the page as one element per formula, not as markup the MDX compiler parses and compiles element by element, which was most of the build time of a math-heavy vault. On one development machine, a cold build of 500 notes with 25 formulas each takes 3.5 s and 2.1 GB instead of 12.9 s and 6.4 GB, and 2,000 notes with about one formula each take 7.6 s instead of 8.4 s. The rendered DOM is unchanged.
- Media embeds cover every form Obsidian's docs list. Audio, video and PDFs written as markdown images (`![](tone.mp3)`, `![](doc.pdf#page=2)`, as Obsidian writes them with `Use [[Wikilinks]]` off) become players and PDF frames instead of a broken `<img>`; a PDF no longer gets inlined into the page as a `data:` URL. `![[doc.pdf#page=3&height=400]]` applies both knobs, in notes and canvas cards. `![](https://www.youtube.com/watch?v=…)`, `youtu.be`, Shorts and `![](https://x.com/…/status/…)` (or `twitter.com`) are framed from YouTube's and X's embed URLs, with the size syntax honoured. An attachment missing from disk now gets the URL it will be published at, under `vaultRoutePrefix`, so the embed works as soon as the file is added.
- `mermaid`, `mathjax-full`, `@excalidraw/excalidraw`, `maplibre-gl`, `lucide-static` and `react-force-graph-2d` are optional peer dependencies. Install them only for the features that need them. A site built without `react-force-graph-2d` no longer fails with "Module not found": the plugin aliases the import away, warns at build time, and the graph panel lists the pages with an install hint instead of drawing the graph.
- `rspress dev` no longer crashes with "attempted to read from stolen value" or "Compilation dependencies are not available while a compilation pass is holding the module graph artifact" when pages are opened or hovered in quick succession. Rspack 2.2.2 to at least 2.2.8 starts the next build while a finished one is still completing; the plugins now hold Rspack invalidations that arrive in that window and replay them once it ends.
- Runs on Node ≥ 22.14 on Linux, macOS and Windows. CI exercises all three.
