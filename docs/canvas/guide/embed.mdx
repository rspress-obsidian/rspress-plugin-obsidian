# Embedding

Besides its own page, a published board can appear inside any other page. Use
this when a board illustrates a docs page or a note. The board must be one the
Canvas plugin publishes: a `.canvas` file under its `vaultRoot`.

## In an MDX page

`<CanvasEmbed>` is available in every MDX page without an import. `src` is the
board's path relative to `vaultRoot`:

```mdx
<CanvasEmbed src="Demo.canvas" />
```

<CanvasEmbed src="Demo.canvas" />

## In a note

In a note or docs page, Obsidian's embed syntax renders the same component, and
a wikilink links to the board's page:

```md
![[Demo.canvas]]
[[Demo.canvas|The demo board]]
```

![[Demo.canvas]]

The board above came from `![[Demo.canvas]]`, and [[Demo.canvas|this link]]
comes from `[[Demo.canvas|this link]]`. If the Canvas plugin does not publish
the board, both forms link to the raw `.canvas` file instead.

## How an embed behaves

An embed has the same cards, edges and controls as the board's page, with two
differences:

- A plain scroll wheel keeps scrolling the page. The board zooms with
  `Ctrl`/`⌘`+wheel or a trackpad pinch, or with any wheel once you have clicked
  into it.
- An embed is always read-only, even with `editable: true`.

Each board remembers its own pan and zoom, so two boards on one page do not
share them.

## Props

An embed does not read the `canvas()` options. Pass these props when you need
them:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `src` | `string` | required | The board's path relative to `vaultRoot`, e.g. `Projects/Board.canvas` |
| `linkPreview` | `boolean` | `true` | Show link cards as website previews; see [`linkPreview`](./configuration.md#linkpreview-and-iframesandbox) |
| `iframeSandbox` | `string` | `"allow-scripts allow-same-origin allow-popups"` | `sandbox` attribute of link-card previews |
| `fileRoutePrefix` | `string` | none | Route prefix for file cards the build did not resolve; `![[Board.canvas]]` passes the markdown plugin's `vaultRoutePrefix` |
| `basePath` | `string` | the site's `base` | Load a board published by a different site, e.g. `basePath="/docs"` |
